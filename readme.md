1주차 (개발 환경 구축): GitHub 가입 및 저장소 생성, Python과 VSCode 설치, print 명령어 테스트
2주차 (변수와 연산): 사용자 입력 처리 및 데이터 형변환, 거스름돈 계산 알고리즘을 통한 산술 연산자 학습
3-4주차 (제어문과 반복문): 중첩 루프 활용, 플래그 변수와 break문을 사용한 소수 판별 알고리즘 효율화
5-6주차 (함수와 리스트): 리스트 컨테이너 활용 데이터 관리, sum, max, min 함수 기반 데이터 분석, 소수 판별 기능의 함수 모듈화
7-8주차 (자료구조 및 클래스): 튜플, 세트, 딕셔너리의 특성 비교 및 활용, 클래스를 활용한 데이터와 기능의 캡슐화 이해

프로젝트: 비밀번호 생성기
Tkinter 라이브러리를 활용하여 실시간 유효성 검사 및 강도 측정 기능을 갖춘 GUI 기반 애플리케이션입니다.

주요 기능
무작위 비밀번호 생성: 대소문자, 숫자, 특수문자를 혼합한 비밀번호 자동 생성

실시간 강도 측정: 입력된 비밀번호의 조합과 길이를 판별하여 보안 강도(취약함, 사용 가능, 보안 강력) 출력

예외 처리 및 실시간 경고: 허용되지 않은 문자 입력 시 화면에 즉각적인 경고 메시지 표시

클립보드 복사: 복사 버튼 클릭 시 비밀번호가 클립보드에 저장되며 UI 피드백 제공

비밀번호 숨김 및 표시: 토글 버튼을 통한 마스킹 기능 지원
