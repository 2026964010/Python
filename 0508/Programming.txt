힌트: 딕셔너리 안에 리스트도 넣을 수 있다.
날짜를 입력하시오: 2020 3 4
일정을 입력하시오: "파이썬 과제 제출!!"

날짜를 입력하시오: 2020 4 2
일정을 입력하시오: "파이썬 프로젝트 제안서 발표!!"
정답:
schedule = {}
while True:
    date = input("날짜를 입력하시오: ")
    if date == "":
        break
    event = input("일정을 입력하시오: ")
    if date not in schedule:
        schedule[date] = []
    schedule[date].append(event)
    print()

"최근에 가장 떠오르는 프로그래밍 언어"

13. 문자열을 받아서 글자의 개수와 숫자의 개수를 계산하여 딕셔너리로 작성하는 프로그램을 작성하라.
힌트: sum(1 for x in myString if x.isalpha())을 사용하면 글자의 개수를 쉽게 계산할 수 있다.
"Hello World123" -> { "LETTERS":10, "DIGITS":3 }
정답:
s = input("문자열: ")
result = {
    "LETTERS": sum(1 for x in s if x.isalpha()),
    "DIGITS":  sum(1 for x in s if x.isdigit())
}
print(result)
